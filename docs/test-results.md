## Выводы и повторные проверки

**Задержка запуска HTTP API.** На этапе разработки снимок стека faulthandler показал обратный поиск имени. Для числового адреса исключён вызов socket.getfqdn. Обновлённая версия успешно прошла API-01 и API-03.

**Навигация Android.** Android Lint обнаружил устаревший обработчик системного возврата. В версии для испытаний действует OnBackInvokedCallback. Проверка возврата вошла в AND-05.

**BUG-001 · Проверка адреса Android.** Средняя серьёзность. Адрес bad/path принимался, хотя поле предназначено для имени или IP. Отладчик jdb показал, что URI выделял узел bad и путь /path. Теперь путь, строка запроса и фрагмент отклоняются до сетевого запроса.

Первоначально пройдено 27 из 28, ошибок 1. После исправления BUG-001 пройдено 28 из 28, ошибок 0. AND-04 повторно получил статус Passed. Адрес с путём и порт 0 отклонены до сетевого запроса. Показаны разные сообщения.

Приложение Android проверено на эмуляторе на том же Mac. API ограничен loopback-интерфейсом. Испытания на физическом телефоне и измерение производительности относятся к отдельным проверкам.

Проверенные функции готовы к демонстрации в учебной конфигурации.
